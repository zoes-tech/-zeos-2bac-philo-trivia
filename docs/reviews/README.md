# Internal accuracy audits

These reports are a **second-pass audit of the explanation text**, not a teacher
sign-off.

Each file records, for one 2BAC module:

- how many entries were audited;
- which entries were corrected, with the old and new text and the reason;
- which entries are uncertain and need a human decision.

The audit checks three things per question:

1. Does the explanation justify the marked correct answer?
2. Is another option defensible under the Moroccan curriculum?
3. Is the philosopher or position attribution accurate?

Only clear errors are edited. Style is left alone, and uncertain items are
flagged rather than rewritten. A philosophy teacher should still review the
flags and, eventually, the whole set before the explanations are described as
"reviewed" instead of "شرح مبسط".
